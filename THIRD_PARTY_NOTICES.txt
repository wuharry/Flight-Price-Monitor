fast-flights Google Flights URL format
====================================

The public Google Flights URL field mapping and query parameters used by
src/providers/google-flights-url.ts are adapted from the fast-flights project's
documented protobuf schema and query URL builder. The TypeScript wire encoder,
decoder, URL validation, browser traversal, and quote validation were written
for this project; the fast-flights Python package is not a runtime dependency.
