Flight Monitor

部署設定與航班監控管理 · 僅在這台電腦開啟

1. 部署設定精靈

先填入服務資訊並儲存。金鑰留空會保留原值，已儲存的金鑰不會顯示。

儲存只更新這台電腦的 .env。已部署的 Cloud Run 不會自動更新。測試寄件人 onboarding@resend.dev 只能寄到你的 Resend 帳號信箱。

產生 Cloud Shell 部署指令

適用於已建置 monitor:v1、建立服務帳戶及資料表的專案。先在 Secret Manager 更新三筆密鑰，再執行產生的指令。雲端部署固定先用 preview 測試。

開啟 Secret Manager

  • flight-monitor-supabase-key：Supabase key
  • flight-monitor-resend-key：Resend key
  • flight-monitor-recipient：收件 Email

2. 監控規則

請先儲存設定，再讀取規則。

新增監控

Supabase 模式會直接更新雲端規則，下一次 Job 執行生效。不會立即查價或寄信。票價不含付款手續費及加購項目。
